阵容 / 六位讲者

写书的人，都在这张桌子上

作家、译者、古籍修复师、插画师、装帧设计师与声音纪录者。两日所有环节均含在门票内，工作坊需在预约时锁定席位。

沈

沈砚秋

小说作家 / 《纸上的城市》作者

开幕对谈 / 城市记忆与写作

在报社跑了十一年市政新闻，后来把这些街巷写进两本小说。对谈中她会聊记忆如何被城市改写，以及写作者如何反过来改写城市。

林

林晚枝

文学译者 / 译有《夜航书简》

对谈 / 从铅字到像素

从油印稿排到电子稿，她见证翻译这件事从铅字车间搬进笔记本电脑。对谈现场将带来三枚真实的铅字实物传阅。

陆

陆秉文

古籍修复师 / 从业二十二年

工作坊 / 亲手排一行铅字

一页虫蛀的清刻本在他手里要过二十一道工序。工作坊演示托裱与补洞，每位学员可上手为一页仿宋纸补洞。

枣

阿枣

插画师 / 藏书票创作者

工作坊 / 刻一枚藏书票

刻了八年藏书票，最大的一枚也只有扑克牌大小。工作坊提供椴木板与刻刀，成品可直接盖在自己的书扉页上。

周

周野

书籍装帧设计师 / 书脊逾四百种

讲座 / 书脊上的设计史

他认为书脊是一本书的立面与门面。讲座从一百五十年前的布面精装讲起，现场配三十种实物书脊轮流传阅。

何

何声

声音纪录片主播 / 《书店的一年》

夜场 / 声音纪录片放映

他花一年录下这家书店的四季：梅雨声、翻页声、打烊后的冰箱声。夜场放映完整版，映后设半小时谈。
