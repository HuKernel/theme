Z 轴堆叠 / L1 至 L3

高度系统 / Elevation Tokens

三级阴影，三种高度

深度只分三档，多了就变成噪音。每张卡片用自身所处的层位演示对应的阴影，悬停时抬升一层。

L1 基面

Surface 基面层

承载静态信息：表格行、列表项、目录条目。默认停在 Z 轴第一层，仅以极浅投影交代与纸面的距离。

--elev-1 / 0 1px 2px + 0 2px 6px rgba(15,23,42,.08)
L2 抬升

Raised 抬升层

承载可操作内容：卡片、检索输入组、堆叠案卷。指针悬停时从 L2 抬到 L3，动作换来高度。

--elev-2 / 0 4px 10px + 0 12px 28px rgba(15,23,42,.10)
L3 悬浮

Floating 悬浮层

承载决策与全局：批示卡、审批面板、主操作。离纸面最远，投影最深最散，一律压在最上。

--elev-3 / 0 8px 16px + 0 28px 56px rgba(15,23,42,.16)

基线之下是纸面本身：页面底色 #F8FAFC，无投影、无描边，一切层级自它而起。

案卷堆叠 / Stacking

一摞案卷，一层一个层位

装订成册的案卷在界面上同样遵守 Z 轴：堆叠时只露出纸边，展开后各归各位。顶层 L3 承担当前操作，底层 L0 贴住纸面，投影随层位逐级消退。
