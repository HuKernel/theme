风格说明 / Parallax Storytelling

这页视差是怎么搭的

多层深度由滚动驱动的 transform 完成, 每章一个 sticky 场景五层速率, 不依赖任何视差库。

设计令牌

  • 色彩 #2563EB / #6B25EB / #EBAD25
  • 底色与正文 #F8FAFC / #0F172A
  • 圆角基准 14px / 字体 Inter + Noto Serif SC
  • 章节色板: 黎明靛 / 林线青 / 岩脊灰蓝 / 雪线亮蓝 / 顶峰夜金

视差结构

  • 远景 0.10 / 中景 0.16-0.24 / 近景 0.32-0.34 / 前景 0.44 / 路标 0.52
  • 层图形全部为 CSS clip-path / 渐变 / data-URI SVG
  • will-change: transform 合成层提升, rAF 节流滚动
  • scroll-snap proximity 让滚动即翻页

无障碍与降级

  • prefers-reduced-motion: 关闭全部视差, 内容平铺可读
  • 移动端自动降级为单速 0.16
  • 页首跳过链接 + 章节锚点导航 + :focus-visible
  • 正文对比度均不低于 4.5:1
