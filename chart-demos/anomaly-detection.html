02 / 图注与判据

阈值带与异常判据

异常的合法性来自判据的透明：把带、阈值与规则印在图上，读者才能复核每一次报警，而不是被动接受红点。

图 10-a 中，浅黄底为警戒带（3.5 至 5.0 与 9.5 至 11.5 mg/L），红色虚线为触发阈值；蓝线在安全带 5.0 至 9.5 内自然波动，均值 7.1、中位数 7.2 mg/L。三起异常均以实心红点加外环加事件号标出，图中直接注明原因，状态以文字与方向符号传达，不依赖颜色单独成立。

  • 阈值判据：瞬时值低于 5.0 或高于 9.5 mg/L 即触发（A1、A2、A3 均由此判定）
  • 统计判据：偏离 7 日滚动基线超过 3 倍标准差，用于捕捉缓变漂移
  • 变率判据：24 小时降幅或升幅超过 2.0 mg/L（本例 A1 日降幅 3.0，A3 日升幅 3.4）
  • 三条满足其一即标记，并写入持久事件列表与数据表，警报不依赖悬停存在

安全带 5.0 至 9.5 / 警戒带 3.5 至 5.0 与 9.5 至 11.5 / 判定 v<5.0 或 v>9.5 或 24h 变幅超 2.0 或偏离基线超 3σ

03 / 无障碍后备

持久事件台账

官方无障碍后备要求：异常事件列表加叙述性警报摘要，警报常驻而不依赖悬停。下表即图 10-a 的等价后备，读屏与键盘用户无需接触图形即可取到全部事件。

A1 / 偏低

09-18（第 9 日）

读值 3.8 mg/L

命中判据：低于下阈值 5.0，且 24 小时降幅 3.0 触发变率判据。

原因：台风外围暴雨，地表径流携入有机物，水体耗氧激增。

处置：当日 16 时启动增氧泵并加密巡检，次日回升至 5.4，48 小时后回归安全带。

A2 / 偏低

09-26（第 17 日）

读值 4.3 mg/L

命中判据：低于下阈值 5.0，24 小时降幅 3.3，为期内最深单日跌落。

原因：上游河道清淤扰动底泥，叠加夜间溶氧低谷。

处置：函告施工方调整作业时段，采样加密为每 4 小时一次，两日后恢复至 6.5。

A3 / 偏高

10-03（第 24 日）

读值 11.2 mg/L

命中判据：高于上阈值 9.5，24 小时升幅 3.4，进入上警戒带。

原因：连续晴热后藻类增殖，午后光合作用致溶解氧过饱和。

处置：挂牌观察叶绿素浓度，未发生鱼类死亡，次日回落至 8.8。

04 / 选型边界

何时使用，何时退避

本图型的分工很明确：时间序列负责讲清基线，高亮层负责讲清例外。例外若已固化成类别，就该换一种图型。

适用

用时序守候离群

监测时间序列中的离群点

  • 向用户提示运营数据的意外尖峰或骤降，异常占比低（本例 3/30）
  • 需要"基线加例外"的双层叙事：先证明平常，再指出反常
  • 读者需要沿时间复核事件前后的恢复轨迹（如 A1 后两日回升）

不适用

换图型的三种情形

改用带高亮的条形图或事件流

  • 异常是预定义类别（如已知故障码）时，改用带高亮的条形图
  • 实时场景且无暂停控制时不应使用：滚动刷新会吞掉悬停与聚焦
  • 读者只关心事件汇总时，持久事件列表比折线更直接

数据上限：流式渲染在 60fps 以内时改用 Canvas；批处理最多 10,000 点；异常必须作为独立数据层标记，不与主线混绘。

05 / 复核

误报与漏报的取舍

阈值不是真理而是一次下注：收紧买安全付人力，放宽买清净付风险。取舍要写在图注里，让读者知道你押了哪一边。

收紧阈值

误报增多

false positive / 狼来了效应

若下阈值自 5.0 收至 5.5 mg/L，本例 09-19（5.4）与 09-27（5.6）两次事件后的正常回升日即被误判，30 日内平添 2 起误报。代价是复核人力被稀释，真警报淹没在噪声里，值守人员逐渐无视所有红色。

本例模拟 / 阈值 5.5 时误报 2 起，漏报 0 起

放宽阈值

漏报风险

false negative / 不可逆代价

若下阈值放到 4.0 mg/L，A2（09-26，4.3）即漏报，鱼类窒息的风险窗口被无声略过。低氧对生态是不可逆伤害，而一次误报的代价只是复核一通电话：对这类指标，漏报几乎总是更贵的那一边。

本例模拟 / 阈值 4.0 时漏报 1 起（A2），误报 0 起

  • 监管红线类指标宁可误报：阈值贴红线设置，误报交由人工二次确认
  • 高频自动场景先粗筛后复核：放宽阈值降噪，配滑动窗口统计判据补漏
  • 分层设定：值守屏用紧阈值即时告警，周报月报用 IQR 或 3σ 统计判据降噪
  • 调整即回放：每次改阈值后回放历史 30 日数据，核对误报漏报计数再上线

落地 10-d

实现要点

D3.js / Plotly / ApexCharts

  • D3.js：阈值带画为背景 rect，异常层单独 append，描边动效用 stroke-dashoffset
  • Plotly / ApexCharts：用 shapes 或 bands 承载警戒带，避免和序列混在一个 trace
  • 流式数据：60fps 以内改用 Canvas 渲染主线，SVG 只保留异常层与标注，保证可聚焦
  • 事件列表常驻：警报同时写入持久列表，读屏与键盘用户无需悬停也能取到全部事件

本页样张即为手写内联 SVG：无依赖、可打印、异常点可 Tab 聚焦。
