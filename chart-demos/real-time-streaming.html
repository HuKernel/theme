02 / 滚动窗口机制

窗口、速率与降采样的取舍

与产品级的实时监控页（如本库的 水质实时监测看板）不同，本页是图鉴层：只拆流式面积图这一编码的三个机构件。窗口定多宽、数据推多快、旧点怎么聚合，三个参数互相咬合，定错任何一个，图都会说谎或失效。

取舍甲

窗口宽度的赌注

window / 60s 对照 300s

本例取 60 秒：晚高峰的秒级锯齿与爬坡斜率都看得清，但一分钟之前的世界已经不在图上。值守场景要的正是这个——当前 60 秒的状态，而非历史复盘。若把窗口拉到官方上限 300 秒，同样 876 像素宽的图面上每点仅分得约 3 像素，秒级波动被压成糊带，换来的是五分钟趋势可辨。

60s 窗口 / 点距 14.8px / 300s 窗口 / 点距 2.9px

取舍乙

速率与降采样咬合

velocity / downsample

推入速率越高，窗口能维持的原始点越少：300 点缓冲里装 1Hz 可以存 5 分钟原始，装 5Hz 只够 1 分钟。官方解法是旧段聚合、近端原始——旧数据四点并一点或两点并一点，保形态丢细节；近端永远逐点，保当前判断。降采样必须用均值或中位数聚合，不能用抽点，否则尖峰被随机保留或丢弃。

1Hz 存 300s / 5Hz 仅存 60s / 聚合用均值不用抽点

数据上限：官方阈值明确：高频流式必须改用 Canvas 或 WebGL 渲染；缓冲保留最近 60 至 300 秒；滚动查看更旧数据时对旧段降采样。本页为样张以手写 SVG 演示机制，60 点全原始。

键盘操作

官方要求逐条落实

pause / zoom / reset / focus

  • 暂停与继续：暂停推送按钮切换，Tab 聚焦后回车或空格触发，图面即冻结为静态快照
  • 加减缩放：加号与减号按钮三档切换纵向量程，重置按钮一键恢复 900 MW 全量程
  • 聚焦即读值：当前值直标常驻图内，读数行 role 状态语义，暂停后可从容听取
  • 减少动态：系统偏好开启时不启动推送、无呼吸动画，静态快照加表格即为完整等价物

04 / 选型边界

何时使用，何时退避

流式面积图买的是"此刻"：数据推得够快、读者要的只是当前状态时它最强；一旦读者要的是历史复核，就该退出。

适用

用滚动窗口守此刻

live monitoring dashboards

  • 物联网与运维看板，数据以不低于 1Hz 持续更新（本例 1 点每秒）
  • 用户需要在一眼之间取到当前值与方向（值守屏、调度台）
  • 总量可分解为两三个分量的场景（本例民用加商业堆叠为片区负荷）
  • 有暂停控制且尊重减少动态偏好，刷新不打断读屏与聚焦

不适用

换图型的三种情形

periodic-refresh line chart

  • 更新频率低于每分钟一次时，改用周期刷新的普通折线图，流式机制是浪费
  • 无暂停控制的闪烁内容不应使用：吞掉键盘焦点与读屏，且伤害前庭敏感用户
  • 读者需要复核完整历史时，流式窗口装不下，改用可回放的折线图加数据表

05 / 备选形态

走马灯数值带与移动仪表

官方备选两个：只关心数字本身时用走马灯，只关心当前值离上限多远时用移动仪表。两者都比面积图更轻，也更容易做到无闪烁。

备选 23-b1

走马灯数值带

Ticker Tape

数值按时间 newest 向左滚动，最新一条以绿色加粗，方向以升降价符号传达。适合空间只剩一条横带的场景；损失全部形态信息，只剩数值序列。

备选 23-b2

移动仪表

Moving Gauge

指针随推入平滑移动，回答"离上限还有多远"这一个问题。色带之外必须给数字与文字（833 MW 与 83% 直标），告警不靠颜色单独成立；损失历史与方向，只剩当前位置。
