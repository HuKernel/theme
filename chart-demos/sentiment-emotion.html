词云读数的三种失真

同一语料 / 换一种编码就露出的信息

  • 面积夸大 / 干净 318 对 安静 264 频次只多 20.5%, 字号 54px 对 47px 的视觉面积差让人感觉远不止。
  • 近邻混淆 / 隔音 142 对 泳池 138 词云里几乎同大, 4 次差值完全丢失; 条形图一眼分出。
  • 情感遮蔽 / 蚊虫 96 与 氛围 96 同频异色, 一红一绿抢走注意力, 「频次相同」这个事实反被忽略。

结论 / 词云适合「这堆评价在说什么」, 条形适合「差多少」, 数据表适合「到底是多少」。

取舍规则 / 探索语料用词云, 汇报精确对比换条形, 无障碍交付以数据表为主件、词云为插图。 官方数据量阈值: 50 到 5000 词最优, 超过 5000 先做 top-N 过滤再渲染, 移动端避免使用。

本页语料 4,126 条评价落在官方阈值内; 若只有 30 条评价 (50 条红线), 词云应当整体换掉, 直接给条形或表格。

03不只靠字号与颜色 / 无障碍三道防线

官方风险 risk:high / 后备给足才可用

官方 Accessibility Notes 说得直白: 每个词 / 频次 / 情感都以文本暴露, 尺寸与颜色仅为补充。 词云是官方标注的高风险图型, 落到本页就是三道防线。

  • 防线一 每词可聚焦 Tab 逐一聚焦 40 个词, 状态行读出 词 / 情感 / 频次 / 占比 / 字号; 每词的 aria-label 同样带全这三项。
  • 防线二 过滤即控件 全部 / 仅正面 / 仅负面 / 仅中性 四个按钮带 aria-pressed, Space 或 Enter 生效, 对应官方 A11y Fallback 的键盘要求。
  • 防线三 表格为主件 区块 04 的 40 行数据表可排序, 是官方指定的 primary; 词云是 supplementary 插图。红绿之外, 下划线实线 / 虚线 / 无, 三态形状可辨。

字号从不单独承载频次 (聚焦读值 + 表格同列给出精确数), 颜色从不单独承载情感 (下划线形状 + 表格文本列)。 官方备选图型 Sentiment Arc 与 Radar Chart 可在需要趋势或分维对比时替换。
