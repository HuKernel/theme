图版 02 / 可读性警示与替代

3D 的代价：遮挡、旋转失真与可达性风险

依据 charts.json No.22 官方字段 / 强制 2D 后备

risk:high

官方将本图型可达风险标为 high（高）：颜色与三维位置不得作为信息的唯一载体，必须辅以标签、形状与深度无关线索；并在要求无障碍的环境、移动端语境中直接禁用。三维值在本页通过可聚焦样点与数据表双通道提供。

官方告诫：这些场景不要用 3D

  • 2D 投影已足够：若俯视投影即可复现同等洞察，3D 只增加判读成本。本例即是：窖温与陈化年份 r = −0.985，2D 分面已传达全部结构。
  • 遮挡：前景点遮蔽后景点，深度顺序随视角改变；官方因此要求标签 / 形状 / 深度无关线索，不可仅靠颜色与位置。
  • 旋转失真：旋转改变相对位置的视知觉，同一点在不同视角下远近高低的读数错觉不同，比较型结论不可依赖单视角。
  • 移动端：小屏与触控拖拽放大了遮挡与误读，官方列入禁用清单。
  • 标准商业仪表盘：常规看板场景同样列入官方禁用清单。

替代方案（官方强制）：同一数据的三组 2D 分面投影。三张迷你样均带虚线趋势线，判读结论与 3D 主图完全一致，且无遮挡与视角依赖。这也正印证官方告诫：当 2D 投影已传达同等洞察时，不应使用 3D。
