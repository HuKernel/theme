热力编码的原理只有一句话: 色阶即数值。横纵两维放类别, 颜色深浅放强度, 一张图读完「谁在什么时候最忙」。本页用一条地铁线的 10 个站点 × 06:00-20:00 逐小时客流强度 做完整示范: 连续色阶怎么配刻度, 单向渐变与双向发散怎么取舍, 以及官方无障碍要求——永远不要只靠颜色。 与站内自习室热力风格页不同, 这里聚焦编码原理而非视觉风格。

02色阶取舍 / 单向渐变 vs 双向发散

同一份 ± 偏差数据 / 两种色阶 / 结果完全不同

下面两张迷你矩阵是同一组数据: 四个站点八个两小时班次, 客流相对各自全日均值的偏差百分比。 区别只在色阶。官方 Color Guidance 原文: 渐变用冷 蓝 到 热 红 / 正负数据用发散刻度 / 永远附数字色阶图例。

取舍规则 / 数据只有大小没有方向 (如客流强度本身) 用单向冷到热渐变; 数据围绕基准有正有负 (如相对均值的偏差 / 环比变化) 必须用双向发散, 且中点严格锚定基准值, 别让 0 漂移。 两者的图例都必须带数字刻度, 这是官方 Color Guidance 的硬要求。

03不只靠颜色 / 无障碍三道防线

官方风险等级 / 条件性 / 满足后备才可用

约百分之四的男性读者分不清部分红绿。官方 Accessibility Notes 说得直白: 在格子里印数值或符号, 用纹理和标签叠加色阶, 不要只靠颜色传达信息。落到本页就是三道防线。

  • 防线一 数值直标模式 点上方「直标数值」按钮, 140 格全部印出精确读值; 色觉障碍或黑白打印时, 图仍然是完整的数据图。
  • 防线二 数字刻度图例 连续色阶永远配 min 与 max 刻度, 分箱色阶永远标数值区间; 没有数字的色条只是装饰。
  • 防线三 数据表后备 下方区块 04 给出完整网格数据表与强度摘要; 键盘可逐格聚焦读值, 缩放与重置均有按钮, 不依赖鼠标。

色盲安全替代 / 同一矩阵改用单色明度阶梯

只动明度不动色相 / 六档由浅到深对应 0 到 5 / 黑白打印与色觉障碍下排序依旧成立

012345

换算规则 / 冷热阶的六档直接映射到六档明度, 矩阵结构与读数不变; 若必须保留色相对立, 选蓝橙对侧 (如上方发散色), 避开红绿对; 再叠上直标数值, 就是官方要求的多重冗余。

何时别用热力 / 官方原文: 少于 20 格改用条形图 / 用户需要读取精确值时改直标或表格 / 色盲读者且没有后备方案时不要用。 本页冷热阶的明度从浅到深单调递增, 即使色相不可辨, 深浅仍可排序。
