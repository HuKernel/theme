学名：Decomposition Tree / 次选 Decision Tree / Flow Chart

本页标本取自一家日用瓷工厂的月度质量例会：华澄陶瓷三厂 2026 年 3 月投产 250,000 件， 废品 20,500 件，废品率 8.2%。分解树按工序把这一个数字层层切开， 每个节点都直标件数与占父级比例，任何一层的子因相加都严格回到父节点； 节点可键盘聚焦读值，文末提供完整数据表后备。

总览

3 月废品率 8.2%（20,500 / 250,000 件）。成型支贡献 40.5% 为最大支，其下压制压力波动为最大单因（3,500 件 / 占总废品 17.1%），主因线终点是液压系统泄漏。聚焦任意节点可读出该支明细。

图注 / 逐层追问方法论 / 五步把 8.2% 问到能动手

  1. 01锁定口径

    先钉死分子分母：废品率等于废品 20,500 件除以投产 250,000 件，得 8.2%。口径一变，整棵树作废。

  2. 02第一刀切齐

    按工序切成互斥且穷尽的四支：成型 / 上釉 / 烧成 / 其他。四支占比相加必须回到 100%，否则不许往下钻。

  3. 03逐层追问

    每层只问一句：这一支的差异从哪来。用停机记录与控制图选最大差异的一支继续切，其余支保持不动。

  4. 04落到可控叶因

    追到能指派责任人与参数为止：液压系统泄漏安排检修班组本周处理，能动手的深度就是树的终点。

  5. 05守恒复核

    每层子因件数与占比相加回到父节点，与文末数据表逐行对账，防止分解率对不上。

变体样张 / 鱼骨图对比 与 图形取舍

鱼骨图迷你样：同一批原因词

同一场质量例会的另一块白板：按人 / 机 / 料 / 法四类穷举假设。 鱼骨图产出的是待验证的定性清单，不承载占比数值；主因线仍要回到分解树量化确认。

何时分解树，何时鱼骨

  • 用分解树Decomposition Tree

    指标可量化、父子因果明确，要逐层看占比并继续下钻；BI 演示与 AI 辅助拆解场景的默认答案。

  • 用鱼骨图Fishbone

    原因未明、要拉团队穷举假设的定性场合。产出是待验证的原因清单，不承载数值占比。

  • 用决策树（次选）Decision Tree

    目标是分类规则与预测：叶子是结论或类别，节点问的是判别条件，而非贡献多少。

  • 用流程图（次选）Flow Chart

    关心工序顺序与流转瓶颈，想看「先发生什么」而不是「谁贡献大」时改画流程。

  • 都不用时

    没有明确父子因果（相关不等于因果），或听众只要一页结论摘要而非探索过程。

判断口诀：量化下钻用分解树，穷举假设画鱼骨，规则预测上决策树，只看顺序走流程图。
