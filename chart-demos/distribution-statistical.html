分布箱线 Box Plot

一箱看穿一组数: 箱体是中间 50% 的订单, 红线是中位数, 须是正常极值, 散点是离群单。跨组对比分布时, 它用最小的版面同时交出离散度 / 中心 / 偏态与异常值。

数据类型 Distribution / Statistical / 最佳图型 Box Plot / 次选 Violin Plot / Beeswarm / 无障碍风险 低

四城均为右偏分布: 均值大于中位数 (见表), 长尾拖向高时长一端; 深圳 IQR 最宽 (17 分钟), 说明半数订单的时长跨度最大; 成都箱体最矮且整体最低, 是四城中配送确定性最高的一城。

02 单箱解剖

五数概括的教学式拆解

须长规则: 上界 = Q3 + 1.5 × IQR = 41 + 22.5 = 63.5 分钟, 下界 = Q1 − 1.5 × IQR = 3.5 分钟。落在界线内的最大 / 最小样本 (55 与 18) 成为须端; 界外的 66 / 74 / 88 三个点必须画成散点。这是箱线图判断离群值的既定口径, 不是主观取舍。

03 取舍对照

箱线 vs 直方图 vs 小提琴

同一份深圳样本 (n = 165) 的三种呈现。官方次选还列了蜂群图 (Beeswarm): 每个点即一单真实数据, 20 至 200 点区间最诚实, 点数再多就回归箱线。

为何有每组 20 点下限

四分位数由排序位置决定: 样本少于 20 时, Q1 与 Q3 各自只由三两个点支撑, 单个异常订单就能把箱体扭变形, 分布摘要失去代表性。

官方建议此时改看原始点: 次选蜂群图 (Beeswarm) 让每一单占一个位置, 20 至 200 点区间信息最完整; 点数超出后再回到箱线的聚合视角。

本页四组样本为 165 至 220 单, 均在安全区; 阈值对照图中的 12 单箱仅作反例演示, 不参与结论。

05 无障碍要点

低风险的达成方式

  • 1五数直标: 下须 / Q1 / 中位数 / Q3 / 上须与离群值全部印在图形旁, 不需要悬停也能读全。
  • 2键盘等于悬停: 每个箱体可 Tab 聚焦, 聚焦弹出的统计卡与鼠标悬停完全同源。
  • 3表格后备: 第 04 节统计表 + 分布摘要承担读屏与打印场景, 图形不可达时信息零丢失。
  • 4不只靠颜色: 中位线用加粗 + 数值, 离群值用点形 + 数值, 色弱用户依形状即可区分统计角色。
  • 5样本量门槛: 每组低于 20 点不出箱线 (分布无意义), 本页四组为 165 至 220 单。

工程口径

手写内联 SVG, 无图表库依赖; 悬停与聚焦共用一个提示层, 动效只做一次且尊重 prefers-reduced-motion; 图形颜色沿官方配色, 文字用加深变体保证对比度不低于 4.5 比 1。

图元对比: 箱描边 #1976D2 对白底约 4.6 比 1, 中位线 #D32F2F 对箱体填充约 3.6 比 1, 离群点 #F44336 对白底约 3.7 比 1, 均高于图形件 3 比 1 的要求。
