图表图鉴 / 相关与分布 / 第 04 号标本

相关散点与气泡图

用于探索两个连续变量之间的关系, 并识别数据中的簇与离群点。本页以 28 个真实感咖啡庄园样本演示完整用法: 横轴为种植海拔, 纵轴为杯测分, 点径编码年产量。

标本来源: 图表选型数据 No.04 / 数据类型: Correlation / Distribution / 最佳图型: Scatter Plot or Bubble Chart

01 / 标本大图

海拔越高, 杯测分越高吗

先看图, 再看数: 主体样本呈强正相关, 但河谷合作社与山脊试验田两处离群把全样相关系数从 0.94 拖到 0.65 — 这正是散点图要先读形再读数的原因。

02 / 气泡变体

第三维: 点径编码复购率

当两个连续变量之外还存在第三个量纲时, 气泡图用面积 (而非半径) 编码它。下图横轴为门店日均出杯量, 纵轴为坪效, 点径对应月复购率。

03 / 过密对策

点太密时: 降透明度或改热区

同一份 48 点数据: 左图全不透明, 重叠区糊成墨团, 无法判断浓度; 右图将不透明度降至 0.65, 叠加处自然显影, 再以蓝到红梯度色轴的热区标出两处高密度核心。

04 / 无障碍要点

颜色可以强化, 但不能是唯一区分

本图型官方风险等级为「有条件」。核心做法: 标记形状与直接文字标注并用; 下图用圆 / 方 / 三角区分三个处理法簇, 簇旁直接写名, 即使全部去色也可读。

本页的五项落实

  • 1键盘逐点读值 / 大图中每个点可 Tab 聚焦, 聚焦即显示庄园 / 海拔 / 杯测分 / 年产量。
  • 2刷选的键盘替代 / 拖拽刷选改为带标签的海拔起止区间输入 (见 05 节), 结果变化以 aria-live 播报。
  • 3形状与直接标注并用 / 见左图: 三种标记形状对应三个处理法, 簇旁直接写名。
  • 4颜色不作唯一区分 / 全页单色系也能读; 蓝 / 红梯度仅用于密度色轴, 且配有文字刻度。
  • 5可见数据表后备 / 28 行样本全量落表, 附相关系数与趋势摘要 (见 05 节)。

05 / 数据表后备

看得见的表, 才是无障碍的图

散点图的无障碍后备方案: 提供可见数据表与相关性摘要; 刷选交互改用下方带标签的起止区间输入, 调整后表格与大图同步筛选, 区间外的点自动变淡。

06 / 数据量分档

点数决定渲染策略

同一图型, 三种量级三套做法; 跨档硬画会卡顿或糊团, 降档则浪费保真度。三档阈值摘自选型数据 No.04 的 Data Volume Threshold 字段。

少于 500 点

SVG 逐点渲染

本页 28 点即此档: 每点可键盘聚焦 / 可直接标注, 保真度与无障碍上限最高。

500 至 5000 点

Canvas 加不透明度 0.6 至 0.8

换画布保性能, 降透明度让重叠处自然显影为密度, 见 03 节右图。

5000 点以上

六边形分箱或先聚合

不再逐点: 改热区或分箱统计, 蓝 / 红梯度色轴编码箱内计数。
