热力矩阵即主角

自习室是热力图最有解释力的场景之一: 座位占用率天然落在 0 到 100 之间, 冷色代表空座, 暖色代表满员。本页以拾光自习室旗舰店的运营样本为数据, 用同一套蓝到红的六级色阶贯穿三个视角: 年度日历热力、时段与星期矩阵、楼层区域平面。每一格都标注数值或提供悬停提示, 颜色不是唯一的读取通道。

04落地要点

  • 色阶分级明确 六级阈值 20 / 40 / 60 / 75 / 90, 分级图例常驻视口
  • 连续映射可读 渐变图例给出 0% 至 100% 的连续取值范围, 冷暖方向固定
  • 悬停即数 日历每格 title 提示完整日期与当日占用率
  • 色盲替代通道 矩阵与区域全部直标数值, 不依赖颜色单通道读取
  • 渲染性能 365 格上下使用纯 CSS grid; 万级数据量建议切换 canvas 渲染
  • 语义一致 同一套蓝到红色阶贯穿日历、矩阵与平面, 学习成本为零
