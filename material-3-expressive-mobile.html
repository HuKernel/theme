表达性组件 / 四个可验证的细节

tonal 色阶分层

层级不依赖投影强度，而是由 surface / container / high / highest 覆盖色逐级加深表达；页面背景不使用纯白，tonal elevation 取代硬阴影。

surface / 页面底色 surface-container / 区块 secondary-container / 选中态 primary / 主操作与进度

胶囊与大容器圆角

所有按钮、chip、 segmented 控件一律 borderRadius 999 的胶囊形；卡片与底部导航取 16 至 28 的大容器圆角，FAB 则取 24。

胶囊按钮 筛选 chip 28 圆角

state layer 状态层

悬停与按压不再用 opacity 0.5 的写法，而是 8% 至 13% 的同色覆盖层，配合 0.18 秒 emphasized 缓动；键盘焦点由 focus-visible 描边保障。

浮动标签输入

filled 输入框的标签在聚焦或已有内容时上浮缩小，位移动画同样走 emphasized 缓动，替代生硬的 label 换行。

点按输入框，观察标签上浮
